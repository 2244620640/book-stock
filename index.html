本机模式：数据只保存在当前浏览器
怎么免费开通云同步（3 分钟）
  1. 打开 supabase.com 注册（GitHub 或邮箱），新建一个免费项目，区域选 Singapore 或 Tokyo，国内访问更快。
  2. 进入项目 → 左侧 SQL Editor → 新建查询，把 supabase-schema.sql 的全部内容粘进去并运行。
  3. 左侧 Project Settings → API，复制 Project URL 和 anon public 两个值，填到上面两栏。
  4. 左侧 Authentication → Users → Add user，填邮箱和密码创建账号（可关闭 Public signup 防止陌生人注册）。
  5. 回到这里点「登录并同步」。第二台设备填同样的地址、密钥和账号即可。

顾客页 只读

把下面这个网址发给客户：他们只能看到还有哪些库存、可以把书加进选购清单，不能入库出库、也看不到备注和流水。

顾客页怎么才能看到实时库存
  1. 顾客页读的是 Supabase 里的 catalog 视图（只读，匿名可访问，不含内部备注）。
  2. 执行 `supabase-schema.sql` 时会自动建好这个视图和读取权限。
  3. 打开站点根目录的 config.json，把 Project URL 和 anon public key 填进去，保存并重新上传。
  4. 没有配置 Supabase 时，顾客页会读取 catalog.json（用下面的「导出上架清单」生成后上传），数据是导出那一刻的快照。

批量上架照片 自动

选一批照片，自动压缩 → 上传 → 分组生成记录 → 同步上架。一本可以有任意多张照片。

按拍摄时间排序，相邻两张间隔超过设定秒数就算换了一本；每本第 1 张当封面、第 2 张当封底，其余进「整套照片」。单张也能导入。

网络检测

手机连不上、传不了照片时，点一下看看断在哪一步。

数据备份

导出的 CSV 可以直接用 Excel / WPS 打开；JSON 备份用于换设备时完整恢复（含流水）。

安装到手机桌面

用手机浏览器打开本页 → iPhone 点 Safari 的「分享」→「添加到主屏幕」；Android 点 Chrome 右上角「⋮」→「安装应用 / 添加到主屏幕」。之后可像 App 一样全屏使用，断网也能打开查看。
